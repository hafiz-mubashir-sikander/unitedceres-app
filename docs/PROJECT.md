# UnitedCeres — Project Overview

## Project

**UnitedCeres** is a production mobile application developed for **United Ceres College students**.

The application was completed as a **company/client project at VirtueNetz**.

## My Contribution

I completed the mobile application **solo** as a Flutter Developer.

The client provided the existing ERP/backend system and its APIs. My responsibility was the mobile application layer and its integration with that backend.

My work included:

- Flutter frontend development
- UI/UX implementation
- ERP API integration
- API request/response handling
- Authentication and session management
- Local storage
- Local state management
- Secure local data handling
- Device-side functionality
- Push notifications
- Biometric authentication
- PDF/document functionality
- Android/iOS implementation
- Production release preparation
- Production-side frontend fixes and improvements

## Client Backend

The backend/ERP system was provided by the client.

This repository does not contain:

- ERP source code
- Backend source code
- Private API implementation
- Internal backend architecture
- Private endpoints
- Client credentials

## Product

The application gives United Ceres College students access to relevant academic and college services from a mobile device.

Examples include:

- Timetable
- Attendance
- Assessment results
- Failure reports
- Leave information
- Invoices
- Receipts
- Announcements
- Notifications
- Helpdesk
- Profile and account functionality

## Delivery

The application was completed as a production mobile application and published for Android and iOS.

See the main README for the current store links.

## Repository Purpose

This repository is a **professional project showcase**, not an open-source distribution of the production application.
